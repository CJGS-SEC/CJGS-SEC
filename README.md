## Featured Security Labs & Projects

### [LimaCharlie EDR & Threat Detection Lab](https://github.com/CJGS-SEC/limacharlie-edr-threat-lab)
* **Objective:** Deployed cloud-managed EDR agents on Windows endpoints using LimaCharlie to monitor process execution, ingest endpoint telemetry, and build custom detection rules.
* **MITRE ATT&CK Mapping:** Simulated persistence via Local Account Creation (`T1136.001`), Privilege Escalation (`T1078`), and Obfuscated Command Execution (`T1027`).
* **Engineering Outcome:** Authored multi-condition YAML D&R rules to flag unauthorized `net.exe` account creations while applying rule-tuning logic to minimize false positives from administrative noise.

### [Wazuh SIEM & Telemetry Sandbox](https://github.com/CJGS-SEC)
* **Objective:** Built an isolated sandbox environment using Wazuh SIEM to capture and monitor raw endpoint log telemetry, brute-force attempts, and credential access anomalies.

### [Threat Hunting & Defensive Security Write-Ups](https://cjgs-sec.github.io)
* **Objective:** Personal technical documentation hub hosted via GitHub Pages breaking down step-by-step methodologies for TryHackMe blue-team rooms, log analysis labs, and SOC scenario challenges.

### [Python Incident Response Automation](https://github.com/CJGS-SEC)
* **Objective:** Developed modular Python scripts to parse local system event logs for Indicators of Compromise (IoCs) and query public threat intelligence APIs (VirusTotal).
