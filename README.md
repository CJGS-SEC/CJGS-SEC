## What I Do

* **Log Triage & Network Telemetry:** Investigating auth failures, parsing DNS/DHCP anomalies, and analyzing PCAP captures to trace lateral movement and suspicious outbound traffic.
* **Identity & Access Management (IAM):** Managing account lifecycles, enforcing RBAC and Conditional Access, and resolving credential/session anomalies across Active Directory and Entra ID.
* **Endpoint Protection & Compliance:** Monitoring EDR sensor health, troubleshooting broken agents, and pushing security baselines via Microsoft Intune.
* **Incident Handling & SOPs:** Applying ITIL framework practices to isolate host threats, manage ticket queues, escalate efficiently, and write clear incident post-mortems.
* **Security Automation:** Writing Python scripts to parse system logs for IoCs and querying public OSINT threat intelligence APIs.

## Featured Security Labs & Projects

### [LimaCharlie EDR & Threat Detection Lab](https://github.com/CJGS-SEC/limacharlie-edr-threat-lab)
* **Overview:** Deployed cloud-managed LimaCharlie EDR agents on Windows endpoints to capture real-time telemetry, execute attack simulations, and build custom detection logic.
* **MITRE ATT&CK Mapping:** Simulated persistence via local account creation (`T1136.001`), privilege escalation (`T1078`), and obfuscated command execution (`T1027`).
* **Detection Engineering:** Wrote multi-condition YAML rules targeting unauthorized `net.exe` usage and tuned out legitimate administrative noise to limit false positives.
